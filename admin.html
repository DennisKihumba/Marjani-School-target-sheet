Add a teacher or admin account

Creates a real sign-in (email + password) for the staff sign-in page. A teacher account is tied to exactly one grade — they'll only see submissions from learners in that grade.

Share the email and temporary password with the teacher directly — they should change the password after first sign-in (via "Forgot password" on the staff sign-in page).

Staff accounts

Important if you plan to reuse an email (e.g. keeping "Grade4@..." for whoever leads Grade 4 next): clicking "Remove access" below only blocks that person from opening a dashboard — it does not free up their email. The email/password sign-in itself lives in Firebase's Authentication system separately, and creating a new account with that same email will fail with "email already in use" until you also delete it there. To fully free up an email: Firebase console → Authentication → Users tab → find the email → delete it. Only after that manual step can a new teacher use the same email address.
